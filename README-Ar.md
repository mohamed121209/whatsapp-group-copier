# ناسخ محتوى جروب واتساب

هذا مشروع أندرويد تجريبي يعمل بالطريقة التالية:
فتح التطبيق ← تفعيل خدمة الوصول ← فتح واتساب ← اختيار الجروب ← الضغط على «جمع» من الشريط العائم ← التطبيق يقرأ النص الظاهر ويحاول التمرير لأعلى وجمع الرسائل ← «نسخ».

مهم جدًا:
التطبيق لا يصل إلى قاعدة بيانات واتساب ولا يفك تشفير الرسائل. يعتمد فقط على محتوى واجهة واتساب الذي تعرضه خدمة الوصول.

البناء من الهاتف:
يمكن رفع المشروع إلى GitHub ثم تشغيل ملف GitHub Actions باسم "Build APK". عند انتهاء البناء سيظهر APK كـ Artifact باسم WhatsAppGroupCopier-debug.

طريقة الاستخدام بعد التثبيت:
افتح التطبيق > فعّل خدمة الوصول > ارجع للتطبيق > «فتح واتساب وبدء الالتقاط» > اختر الجروب > من الشريط فوق واتساب اضغط «▶ جمع».

هذه نسخة تجريبية للاستخدام الشخصي، وقد تختلف إمكانية قراءة الرسائل حسب إصدار واتساب وواجهة أندرويد.
